# AI 시대의 지식과 기술 - 돈 노먼의 제너럴리스트와 스페셜리스트론

원문 노트: [[2026-07-21 Knowledge Is Important Skills are Essential - 번역 원문]]  
원문 파일 경로: `Sources/AI & Automation/2026-07-21 Knowledge Is Important Skills are Essential - 번역 원문.md`

## 한 줄 요약

LLM은 방대한 지식을 다루는 generalist이자 specialist가 될 수 있지만, 현실에서 무언가를 실행하려면 반복 연습과 시행착오로 익히는 skill이 필요하며, AI agent와 robot이 specialist 역할을 맡을수록 사람에게는 전체 목표를 정하고 specialist들을 조율하는 generalist 역량이 더 중요해진다.

## 사용자가 남긴 핵심 메모

- LLM은 여러 분야의 방대한 지식을 빠르게 다룰 수 있다.
- 그러나 현실에서 실제로 무언가를 해내려면 지식만으로는 부족하다.
- 운동, 요리, 글쓰기처럼 숙련이 필요한 일에는 반복 연습과 시행착오를 통해 얻는 감각과 직관이 필요하다.
- AI 에이전트와 로봇도 점차 특정 작업에 특화된 전문가 역할을 맡게 될 것이다.
- 이들을 효과적으로 활용하려면 전체 목표를 보고 작업을 나누고 연결하는 제너럴리스트가 필요하다.
- 앞으로 사람에게 더욱 중요해질 능력은 무엇을 할지 정하고, 여러 전문가와 AI를 조율하며, 결과가 사람들의 삶에 도움이 되는지 판단하는 일이다.
- 한 줄 요약: AI 시대에는 깊이 있는 전문 기술과 전체를 보는 넓은 시야가 함께 필요하다.

## 핵심 구조

### 1. 지식과 행동은 다르다

돈 노먼은 LLM이 지식의 세계에서는 강력하다고 본다. LLM은 여러 영역에 걸쳐 많은 것을 알고 있으므로, 일반적인 의미의 generalist와 specialist 구분을 흔든다. 그러나 물리적 세계로 나오면 문제가 달라진다.

- 지식: 읽기, 듣기, 기록, 계산 구조 안에서 다루기 쉬운 것
- 행동: 실제 세계에서 물리 법칙, 상황 변화, 감각, 조작, 시행착오를 다루는 것
- skill: 지식의 한 종류이지만, 설명만으로 전달되지 않고 연습과 경험으로 체득되는 것

핵심 문장으로 정리하면, **지식은 중요하지만 세상에 차이를 만드는 것은 행동**이다.

### 2. Skill은 말로 완전히 설명할 수 없는 지식이다

Norman은 운동선수, 화가, 작가, 셰프의 예를 든다. 책은 원리와 절차를 설명할 수 있지만, 실제 수행의 감각, 직관, 자동성은 설명만으로 얻을 수 없다.

예:

- 운동선수의 몸 감각
- 셰프의 불 조절과 질감 판단
- 작가의 문장 리듬
- 편집자의 판단 감각
- 장인의 도구 사용법

이런 능력은 규칙으로 환원되지 않는다. 의식적으로 배운 지식이 반복을 통해 무의식적 통제와 직관으로 바뀌어야 한다.

### 3. 도구는 전문성을 만든다

인간은 신체적으로는 많은 동물보다 약하지만, 도구를 발명함으로써 affordance를 확장했다. 불, 옷, 무기, 집, 농기구, 요리 도구, 운송 수단, 인지적 도구가 모두 그렇다.

하지만 도구는 대개 전문화되어 있다.

- 망치에도 다양한 종류가 있다.
- 못도 수백 가지 형태가 있다.
- 특정 도구를 잘 쓰려면 그 도구에 맞는 skill이 필요하다.
- 전문 도구는 전문 행동을 가능하게 하지만, 동시에 전문 훈련을 요구한다.

즉 인간의 generalist 능력은 “아무 도구나 바로 잘 쓰는 능력”이 아니라, 필요한 도구를 만들고 배우고 조합하는 능력에 가깝다.

### 4. AI agent와 robot은 specialist가 된다

Norman은 생성형 AI 이후 agent가 필요한 이유를 “행동”에서 찾는다. LLM이 이미 있다면 왜 agent가 필요한가? LLM은 지식을 다룰 수 있지만, 실제 세계나 복잡한 작업 환경에서 일을 하려면 특정 과업에 특화된 actor가 필요하기 때문이다.

AI agent의 특징:

- 특정 과업에 특화됨
- 때로는 특수 도구를 필요로 함
- 여러 agent가 조합되어 원하는 결과를 만듦
- LLM은 agent들을 지휘하는 generalist 역할도 할 수 있음

따라서 AI 시스템은 하나의 만능 두뇌라기보다, specialist agent들의 편대와 이를 조율하는 generalist의 구조로 발전할 가능성이 크다.

### 5. 사람의 역할은 manager, supervisor, director로 이동한다

Norman의 중요한 예측은 사람에게 남는 주요 skill이 “직접 수행”만이 아니라, 여러 specialist를 관리하고 방향을 정하는 능력이라는 점이다.

사람에게 중요해질 판단:

- 무엇을 할 것인가?
- 이 일이 적절한가?
- 이 결과가 합리적인가?
- 인간 삶의 질을 향상시키는가?
- 각 specialist agent의 결과가 전체 목표와 맞는가?

즉 AI 시대의 인간 역량은 단순히 “AI를 잘 쓰는 법”이 아니라 **목표 설정, 조율, 판단, 책임**으로 재정의된다.

## 관찰과 인사이트

### AI가 지식을 대체할수록 skill의 가치는 더 또렷해진다

LLM이 지식 검색, 요약, 설명, 절차 안내를 잘하게 되면 지식 자체의 희소성은 낮아진다. 반대로 실제 맥락에서 결과를 만들어내는 skill, 특히 말로 설명하기 어려운 감각과 판단은 더 중요해진다.

### “전문가 vs 제너럴리스트”가 아니라 “전문가 + 제너럴리스트”다

Norman은 둘 중 하나를 고르지 않는다. 현실 세계에서 specialist는 실행을 담당하고, generalist는 전체 조합과 방향을 본다. AI 시대에도 마찬가지다. 단일 인재가 모든 것을 깊게 잘하기보다, 전문 skill과 전체 조율 능력을 어떻게 결합할지가 중요하다.

### AI agent 조직은 인간 조직과 닮아갈 수 있다

여러 specialist agent를 generalist가 조율한다는 구조는 조직 구조와 비슷하다. PM, 디렉터, 리서치 리드, 디자인 리드가 여러 전문가를 연결해 결과를 만드는 방식과 닮았다. 따라서 AI agent workflow 설계는 단순 자동화가 아니라 조직 설계에 가까워진다.

### 인간의 경쟁력은 “실행 전 판단”과 “실행 후 의미 판단”에 있다

AI와 로봇이 더 많은 실행을 맡을수록, 사람은 두 지점에서 중요해진다.

- 실행 전: 무엇을 해야 하는지, 어떤 문제가 중요한지 정의
- 실행 후: 결과가 의미 있는지, 적절한지, 사람에게 도움이 되는지 판단

이는 HCD/HCD+ 관점과도 연결된다. 좋은 결과는 단순 산출물 품질이 아니라 인간 삶, 환경, 문화, 사회적 맥락에 대한 판단을 포함한다.

## 실무 적용 예시

### 1. AI agent workflow 설계

Norman의 관점을 agent workflow에 적용하면 다음처럼 나눌 수 있다.

- Generalist 역할:
  - 목표 정의
  - 전체 과업 분해
  - specialist agent 선택
  - 결과 통합
  - 품질과 윤리 판단
- Specialist agent 역할:
  - 코드 작성
  - 데이터 정리
  - 리서치 문서 초안
  - 이미지 생성
  - QA 체크
  - 배포 자동화

체크 질문:

- 이 과업은 지식 검색인가, 실제 실행인가?
- 실행에 필요한 specialist skill은 무엇인가?
- 어떤 부분을 agent에게 맡기고, 어떤 판단은 사람이 가져야 하는가?
- agent 결과를 통합하는 generalist 기준은 무엇인가?

### 2. 디자이너/리서처의 AI 시대 역량 정의

AI가 문서 초안, 분석 보조, 프롬프트 생성, 화면 초안을 맡을 수 있다면 사람에게 중요한 역량은 다음으로 이동한다.

- 좋은 문제를 고르는 능력
- 여러 관점의 specialist를 조율하는 능력
- 사용자 삶에 미치는 영향을 판단하는 능력
- 맥락과 제약을 이해하는 능력
- 반복을 통해 체득한 감각으로 결과물을 평가하는 능력
- 자동화된 결과에 책임지는 능력

### 3. Skill 학습과 AI 활용의 균형

AI가 절차를 설명해줄 수 있어도 skill 학습은 생략되지 않는다.

예:

- 글쓰기: AI가 구조와 초안을 줄 수 있지만, 좋은 문장의 리듬과 독자 감각은 반복 작성과 편집으로 배운다.
- 리서치: AI가 인터뷰 가이드를 만들 수 있지만, 현장에서 후속 질문을 던지는 감각은 경험으로 배운다.
- 디자인: AI가 화면을 만들 수 있지만, 제품 맥락과 사용자 행동을 읽는 감각은 프로젝트 경험으로 형성된다.
- 코딩: AI가 코드를 만들 수 있지만, 시스템 경계와 실패 지점을 보는 감각은 디버깅 경험으로 생긴다.

## 체크리스트

- [ ] 지금 다루는 문제는 지식 문제인가, 실행 skill 문제인가?
- [ ] AI가 설명할 수는 있지만 직접 체득해야 하는 감각이 무엇인가?
- [ ] specialist agent가 맡을 수 있는 작업과 사람이 판단해야 하는 작업을 나눴는가?
- [ ] 여러 specialist 결과를 통합할 generalist 기준이 있는가?
- [ ] 결과가 인간 삶의 질에 도움이 되는지 판단하는 기준이 있는가?
- [ ] AI를 쓰면서도 내가 직접 반복 연습해야 할 핵심 skill을 유지하고 있는가?
- [ ] 자동화된 결과를 검토할 enough expertise가 있는가?
- [ ] 도구를 많이 쓰는 것과 skill을 갖는 것을 혼동하지 않는가?

## 한계와 주의점

- 글은 철학적·개념적 에세이에 가깝고, 특정 AI agent 시스템의 성능 검증 데이터를 제공하지 않는다.
- “사람은 manager/director가 된다”는 전망은 설득력 있지만, 모든 사람이 그런 역할로 이동할 수 있는 사회적·경제적 조건은 별도 문제다.
- physical skill 중심 논의는 명확하지만, cognitive skill이 AI와 어떻게 상호작용하며 재편되는지는 더 깊은 논의가 필요하다.
- LLM과 agent가 specialist가 된다는 비유는 유용하지만, 실제 agent의 책임·검증·안전 문제를 자동으로 해결해주지는 않는다.
